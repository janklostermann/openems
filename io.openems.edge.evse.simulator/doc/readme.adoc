= EVSE Simulator Core

This bundle provides the core simulation logic for IEC 61851-1 compliant electric vehicle chargepoints.

== Purpose

The simulator core provides a reusable state machine and physics model for simulating EV chargepoint behavior. It is designed to be embedded within individual chargepoint component bundles (like `io.openems.edge.evse.chargepoint.alfen`) to enable simulation mode without requiring physical hardware.

== Architecture

This bundle contains only the shared simulation core - approximately 300 lines of pure Java code with no external dependencies. Each chargepoint component that wants simulation capability adds this as a dependency and uses the core classes internally.

=== Why a Separate Bundle?

* **Reusability**: The IEC 61851-1 state machine is standardized across all chargepoint types
* **Maintainability**: Single implementation of charging physics (P = U × I)
* **Testability**: Simple, dependency-free classes that are easy to unit test

== Components

=== ChargePointState

Enum representing the six IEC 61851-1 charging states:

[cols="1,3"]
|===
| State | Description

| A | Not connected - No vehicle plugged in
| B | Connected, not ready - Vehicle connected but not charging
| C | Charging - Active charging session
| D | Charging with ventilation - Rarely used
| E | Error - Charging station error
| F | Not available - Charging station unavailable
|===

=== ChargePointSimulatorCore

The main simulation class providing:

* **State machine** with proper transitions (A→B→C→B→A)
* **Physics calculations** for power and energy
* **Per-phase voltage/current tracking**
* **Configurable current limits** (min/max in mA)

== Usage

=== Adding as Dependency

In your chargepoint component's `bnd.bnd`:

[source]
----
-buildpath: \
	${buildpath},\
	io.openems.edge.evse.simulator,\
	...
----

=== Basic Usage

[source,java]
----
import io.openems.edge.evse.simulator.core.ChargePointSimulatorCore;
import io.openems.edge.evse.simulator.core.ChargePointState;

// Create simulator
ChargePointSimulatorCore simulator = new ChargePointSimulatorCore();

// Configure voltages (default: 230V per phase)
simulator.setVoltages(230.0, 230.0, 230.0);
simulator.setPhases(3);

// Simulate vehicle interaction
simulator.plugIn();                    // A → B
simulator.setCurrentLimit(16000);      // B → C (if >= 6A)

// Get current values
ChargePointState state = simulator.getState();
double power = simulator.getPowerWatts();
double current = simulator.getCurrentAmps();

// Accumulate energy over time
simulator.tick(1000);  // 1 second passed
double energy = simulator.getTotalEnergyWh();

// End session
simulator.unplug();                    // → A
----

=== State Transitions

[source]
----
┌───────┐  plugIn   ┌───────┐  current≥6A  ┌───────┐
│   A   │ ────────▶ │   B   │ ──────────▶ │   C   │
│Unplugged│         │Connected│            │Charging│
└───────┘  ◀─────── └───────┘  ◀───────── └───────┘
           unplug              current<6A

           setError()          clearError()
    Any ─────────────▶ E ─────────────▶ A
----

=== Integration Pattern

See `io.openems.edge.evse.chargepoint.alfen` for a complete example of how to integrate the simulator core into a chargepoint component with simulation mode.

Key integration points:

1. Add `simulationMode` config option
2. Create `ChargePointSimulatorCore` instance in activate()
3. In event handler, check mode and either:
   - Read from Modbus (normal mode)
   - Read from simulator (simulation mode)
4. Add control channels for user interaction (plug in, unplug, etc.)

== API Reference

=== Control Methods

[cols="2,3"]
|===
| Method | Description

| `plugIn()` | Simulate vehicle connecting (A→B)
| `unplug()` | Simulate vehicle disconnecting (→A)
| `requestCharge()` | Car requests charging (B→C if current set)
| `stopCharge()` | Car stops charging (C→B)
| `setError()` | Set error state (→E)
| `clearError()` | Clear error (E→A)
| `setCurrentLimit(int mA)` | Set charging current limit
| `setPhases(int)` | Set 1 or 3 phase operation
| `setVoltages(l1, l2, l3)` | Set phase voltages
| `tick(long ms)` | Advance time, accumulate energy
|===

=== Getter Methods

[cols="2,3"]
|===
| Method | Description

| `getState()` | Current IEC 61851-1 state
| `getCurrentAmps()` | Current per phase in A (0 if not charging)
| `getPowerWatts()` | Total active power in W
| `getPowerL1Watts()` | Power on L1 in W
| `getPowerL2Watts()` | Power on L2 in W
| `getPowerL3Watts()` | Power on L3 in W
| `getVoltageL1/L2/L3()` | Phase voltages in V
| `getTotalEnergyWh()` | Total energy delivered in Wh
| `getSessionEnergyWh()` | Current session energy in Wh
| `getSetCurrentMa()` | Configured current limit in mA
| `getPhases()` | Number of phases (1 or 3)
|===
