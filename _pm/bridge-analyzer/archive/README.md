# Archive

This folder contains completed and archived project management items.

## Files

- **tasks-done.md** - Completed tasks organized by date/milestone

## When to Archive

- Move completed tasks from `../tasks.md` to `tasks-done.md` when:
  - A major milestone is complete (e.g., API bundle done)
  - Tasks list gets too long (>20-30 completed items)
  - Sprint/phase ends

- Keep recent completions (last week) in main tasks.md for quick reference
- Archive older items to keep active file manageable

## Archive Format

Group by milestone or date for easy reference:

```markdown
## Milestone: API Bundle Complete (2025-11-25)

- [x] ai: Create BridgeAnalyzer nature interface
- [x] ai: Create OperatingMode enum
- [x] ai: Create package-info.java
- [x] jk: Review and approve API bundle

## Week of 2025-11-18

- [x] ai: Create requirements.adoc
- [x] ai: Set up dev-assets branch
- ...
```
